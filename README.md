# Site Catálogo Patroa - Proxy Vercel

Este projeto mantém o site antigo hospedado no GitHub Pages, mas permite usar o domínio:

https://www.jamileabreu.com.br

A Vercel fará uma rewrite/proxy para:

https://jamileabreurh.github.io/catalogo-patroa/

## Arquivos
- vercel.json
- package.json

## Como usar
1. Crie um novo projeto na Vercel.
2. Suba esses arquivos.
3. Remova www.jamileabreu.com.br do projeto antigo.
4. Adicione www.jamileabreu.com.br neste novo projeto.
5. Adicione jamileabreu.com.br e redirecione para www.jamileabreu.com.br.
